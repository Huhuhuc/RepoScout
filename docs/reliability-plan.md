# 可靠性改进：已确认范围

沿用现有单 Agent，在控制器、采集、检查点和评测层增量改进。相比只改提示词，这能通过程序测试验证；相比引入多 Agent，调用成本和维护复杂度更低。用户已授权改进上一轮列出的不足，继续保持本地、不发布。

1. 两轮补查按缺口和剩余预算推进；新增阅读窗口计为进展，重复查询限制。
2. 每步保存检查点；异常保存部分报告；继续操作创建关联的新任务、复用资料并使用新预算，保留原记录。
3. 补查先仓库官方文档和发布说明，后社区 Issue；外部官方文档只允许仓库已链接且受支持的公开文档站点，限制大小、协议和重定向。
4. 中英文检索词与来源公平分配；Token 预算预留最终提交，避免声称能精确预测供应商计费。
5. 证据检查明确区分摘录存在、来源权威性、版本范围与语义待复核，不把启发式规则包装成语义证明。
6. 真实仓库冻结快照、同资料基线与关闭补查对照；保留旧评测，生成新结果，不混用指标。

验证：控制器两轮闭环、新片段不误停、异常恢复与取消、中文长文、资料公平分配、Token 停止、外部文档边界、评测隔离；真实小样本只作为运行验证。
