# LangGraph 第一阶段验收

实现日期：2026-10-28；收尾核验：2026-11-01。

## 实现

- 可切换 legacy / langgraph，默认 legacy 保持原行为。
- StateGraph 拆分 prepare、decide、tools、review、finish，条件路由支持反复调查与预算停止。
- SqliteSaver 保存资料、反馈、待执行工具、累计模型请求和 Token、已消耗活动时间。
- `/api/tasks/{id}/recover` 恢复同一 interrupted 图任务；数据库条件更新防止重复恢复领取。
- 节点执行前记录未确认标记；对应检查点持久化后清除。未确认远端执行不自动重放。
- 工作台提供执行器选择、恢复入口，轨迹显示节点耗时、工具反馈、累计预算与停止原因。

## 使用

重新安装 requirements.lock.txt 并重启服务。在 DeepSeek 模式选择 LangGraph。
工具反馈在节点结果的「查看记录」内；收尾原因和预算在对应节点记录内。
正常完成、取消、失败或预算耗尽不提供原图恢复，仅服务重启标记 interrupted 的任务可恢复。
节点内部故障与边界间恢复严格区分；不承诺任意时刻重启都能无损续跑，也不承诺模型请求 exactly-once。

## 范围

本轮实现框架与任务内持久化；没有跨任务长期记忆、多 Agent、并行资料工具或新的向量检索。
旧有 12 任务评测结果属于 legacy 版本，不自动归属于 LangGraph。
恢复的进程退出、预算继承与重复领取由自动化测试验证；不将这些测试称为真实模型任意故障下的无损恢复。简历指标应明确数据集规模、评分口径和真实模型 / 脚本测试的区别。
