# 分级调查与评测扩展（2026-10-16）

## 改动
- 修复评测入口在 Windows 非 UTF-8 控制台的中文输出异常；CI 统一 UTF-8，并加入新数据集校验。
- README 安装文件名改为 requirements.lock.txt，更新公开状态与云端 CI 链接；修复历史任务再次使用时策略、预算与复核开关未恢复的问题。
- 新增 auto / deep 策略。auto 先读明确候选 README，用 assess_readme 合并原文摘录与矩阵提交，完整性和原文匹配校验通过后才结束；未知、条件遗漏和错误参数转入现有工具循环。共享 12 次请求、Token、工具与时间预算。复核仍可开启。
- 无候选、超过三个条件、恢复已有资料或工具预算不足时直接深入。API 默认 deep，工作台默认 auto；GitHub / demo 不使用该策略。
- 修复评测器：部分完成不能计入 grounded_correct。
- 真实复核出现“unsupported 被原文支持却判 contradicted”的错误，增加否定判断的明确提示。仍是同模型复核，不保证事实正确。
