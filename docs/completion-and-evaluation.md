## 实现

- 调查与收尾分阶段；接近模型、工具、时间预算时收尾，最后两次模型请求只允许提交报告。
- 最终提交合并结构复查，避免“复查—提交—再次复查”循环；未收到有效提交仍标为部分完成。
- 使用当前状态快照与有界原文窗口构造上下文；完整正文保留在本地，通过 read_source 按需读取。
- 相同只读查询使用任务内缓存；缓存命中仍占工具预算，连续无进展会触发停止条件。
- 未读取的用户指定候选保留为未知，不从比较矩阵中静默消失。
- 页面和 Markdown 导出记录模型请求、Token、缓存命中与提交状态。
