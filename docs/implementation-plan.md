# 第一版实施计划

用户已批准启动 RepoScout。以现有设计和开源调研为依据。

1. 建立来源、证据、要求和比较模型，准备可重复的虚构资料。
2. 建立单 Agent 决策循环，支持演示策略、真实 GitHub 采集、可选 DeepSeek 工具调用。
3. 增加 SQLite 任务、事件、取消与预算控制。
4. 提供可运行中文工作台及报告导出。第一版用无构建步骤的原生 Web 页面，后续可替换 React；后端协议保持独立。
5. 测试证据真实性、预算、取消、模拟与 API 工作流，验证实际公开 GitHub 读取。

不调用付费模型；真实模型效果仍待配置与评测。第一版不声称自动语义核验、全网搜索或全面的搜索覆盖。
