# RepoScout 可运行性、评测与分级调查

承接用户批准的推进顺序。先修复 Windows CI 编码和 README，再补真实多仓库冻结资料，最后提供可选自动策略；原深度模式保留用于对照。

## 设计
- CI 和命令行评测统一 UTF-8。公开状态与操作说明更新，历史验收日期保留。
- 新冻结资料来自三个公开仓库的固定 commit，保存来源 URL、时间、哈希和原文。12 个单条件任务涵盖支持、明确限制及资料未提及；不是跨仓库联合选型，也不伪造冲突样本。旧数据不覆盖。
- 修复评测器：只有完成、状态匹配且引用有效才计入 grounded_correct；新增资料完整性校验。
- 自动策略先读取明确候选 README，用一个结构化调用同时提交原文和判断。证据不完整、参数错误或未知则回到现有调查循环，预算和请求计数共享；深度策略保留不变。复核开关仍生效。
- 本轮不引入多 Agent、向量数据库或公网服务。候选发现算法与 Issue 评论的完善保留为后续独立改进。

## 验收
Windows 非 UTF-8 stdout 也可运行评测；离线评测验证所有哈希和引用；测试快速完成与升级路径及预算；单元测试与 JS 语法通过后提交并推送，观察 GitHub CI。真实模型仅做小范围冒烟，不把离线测试当真实质量结论。
