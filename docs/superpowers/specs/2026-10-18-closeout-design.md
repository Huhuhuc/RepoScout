# RepoScout 收尾设计

用户批准先完成收尾：减少摘录错误、完整冻结对照、可复现演示与面试说明。

- 用确定性的 source_id:start:end 片段编号选择原文。模型选片段，程序验证来源与边界并存储精确原文；保留旧 quote 接口，不使用模糊匹配或忽略格式来放宽引用校验。片段存在并不保证结论正确。
- 固定当前代码和三仓库十二任务，四策略各运行一次。每个策略完成即落盘，保存代码及资料哈希；显式 resume 只补未完成项。禁止覆盖历史结果，记录失败与成本。
- 不在评测中途改模型流程、标签和评分。标签匹配存在局限，应与状态正确性、完成率、引用精确性分别报告。
- 演示提供两条显式付费实时任务命令和一条隔离数据库离线恢复命令。整理 README、验收与面试说明，通过测试后同步 GitHub 并确认 CI。
- 不新增公网服务、多用户或新的 Agent 项目。
